# 🃏 Olle's Poker App

This is a solo side project exploring poker theory, data analysis, and hand visualization with a focus on MTT (Multi-Table Tournament) poker.

This repository currently contains the frontend UI built with React and Vite. Backend services, solver integration, and database support are planned but not yet included.

---

## ✨ Goals

- Build a clean, fast React UI for replaying hands
- Surface key preflop decision details in a visual format
- Help serious MTT players study and review hand histories more efficiently
- Lay the foundation for future backend analysis and solver-driven insights

---

## 🛠 Tech Stack

- **Frontend:** React + Vite
- **Routing:** React Router DOM
- **Backend:** Python (FastAPI planned)
- **Database:** PostgreSQL planned
- **Local dev:** Node.js + npm

---

## 🚧 Current Status

- ✅ React + Vite frontend bootstraps successfully
- ✅ Basic hand replay UI structure available
- ⏳ Preflop hand replay and analysis components in progress
- ⏳ Backend API and database integration not yet implemented
- ⏳ Docker / Compose setup not included in this repository

---

## 🚀 Getting Started

```bash
cd ui
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
